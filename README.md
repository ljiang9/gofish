# gofish —— 终端钓鱼纸牌 (Go Fish)

你 vs 电脑的经典钓鱼纸牌游戏。纯 Python 标准库, 无第三方依赖。

## 玩法

```bash
python -m gofish              # 交互对战: 你 vs 电脑
python -m gofish --auto       # AI vs AI 快速演示
python -m gofish --auto --seed 42
```

- 开局双方各 7 张牌, 牌堆 38 张。
- 你的回合: 问电脑要一个**你手里有的**点数(如 `7` / `J` / `Q`)。
  - 对方有 → 全部交出, 你**继续**;
  - 对方没有 → Go Fish 摸一张, 摸到的正好是你问的点数也可以继续, 否则换边。
- 集齐 4 张同点即成书得 1 分, 共 13 本, 分多者胜。
- 输入 `quit` 退出。

## 设计取舍

- 电脑 AI 采用最朴素的启发式: **问自己手里张数最多的点数**(并列随机)。
  不记牌、不推理对手手牌 —— 诚实地说, 会被会记牌的人类玩家针对。
- 手牌摸空且牌堆还有牌时摸一张续命(简化规则); 双方都没牌且牌堆空时,
  回合自动跳过, 以 13 本书集齐作为终局条件。

## 已知局限

- 只有双人模式(你 vs 电脑), 无多人对战、无存档、无排行榜。
- 交互模式需要终端(tty); 管道/脚本场景请用 `--auto`。
- AI 很弱, 主要是陪玩和演示规则用。
